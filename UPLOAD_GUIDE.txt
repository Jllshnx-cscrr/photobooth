║              📤 SIMPLE UPLOAD GUIDE FOR INFINITYFREE          ║
║                                                                ║
╠════════════════════════════════════════════════════════════════╣
║                                                                ║
║  STEP 1: BUILD THE PROJECT                                     ║
║  ────────────────────────                                      ║
║                                                                ║
║  Open terminal in your project folder and run:                 ║
║                                                                ║
║    npm install                                                 ║
║    npm run build                                               ║
║                                                                ║
║  ⏳ Wait for build to complete...                             ║
║  ✅ A "dist" folder will appear!                              ║
║                                                                ║
╠════════════════════════════════════════════════════════════════╣
║                                                                ║
║  STEP 2: FIND THE DIST FOLDER                                  ║
║  ──────────────────────────                                    ║
║                                                                ║
║  Location: C:\xampp\htdocs\Photobooth\dist\                   ║
║                                                                ║
║  Inside you'll see:                                            ║
║    📄 index.html                                               ║
║    📁 assets (folder with JS and CSS)                          ║
║    🖼️ camera.svg                                              ║
║                                                                ║
╠════════════════════════════════════════════════════════════════╣
║                                                                ║
║  STEP 3: UPLOAD TO INFINITYFREE                                ║
║  ────────────────────────────                                  ║
║                                                                ║
║  1. Login to InfinityFree control panel                        ║
║  2. Open "File Manager"                                        ║
║  3. Go to "htdocs" folder                                      ║
║  4. Upload these 3 things FROM THE DIST FOLDER:                ║
║                                                                ║
║     ✅ index.html                                              ║
║     ✅ assets folder (entire folder)                           ║
║     ✅ camera.svg                                              ║
║                                                                ║
║  ⚠️ IMPORTANT: Upload the FILES INSIDE dist, not the folder   ║
║                                                                ║
╠════════════════════════════════════════════════════════════════╣
║                                                                ║
║  STEP 4: CREATE .htaccess FILE                                 ║
║  ───────────────────────────                                   ║
║                                                                ║
║  In InfinityFree File Manager, create new file ".htaccess"     ║
║  In the same folder as index.html, paste this:                 ║
║                                                                ║
║    RewriteEngine On                                            ║
║    RewriteBase /                                               ║
║    RewriteRule ^index\.html$ - [L]                             ║
║    RewriteCond %{REQUEST_FILENAME} !-f                         ║
║    RewriteCond %{REQUEST_FILENAME} !-d                         ║
║    RewriteRule . /index.html [L]                               ║
║                                                                ║
║  Save the file.                                                ║
║                                                                ║
